This repository contains the implementation for our tool **VessQC** and the corresponding manuscript "Bridging 3D Deep Learning and Uncertainty-Guided Curation for Analysis and High-Quality Segmentation Ground Truth" submitted to **ISBI 2026**. 

**VessQC** is an open-source, human-in-the-loop tool designed for the efficient, uncertainty-guided curation of large 3D volumetric segmentations, particularly focusing on complex vascular structures.

By integrating state-of-the-art pixel-wise and topology-aware uncertainty maps, VessQC directs user attention to the regions of the segmentation most likely to contain errors, significantly improving the recall of error detection during manual refinement.

This [napari] plugin was generated with [Cookiecutter] using [@napari]'s [cookiecutter-napari-plugin] template.

## Usage Guide

### 1. Input Data Requirements

VessQC requires three core inputs for a volume to be curated. All three files must be aligned and of the same spatial dimensions (e.g., in .tiff or .nii format).

1. **Raw Image Volume:** The original 3D image data (e.g., lightsheet stack).

2. **Segmentation Mask:** A binary segmentation mask.

3. **Uncertainty Map:**  An uncertainty map used to guide curation.

    **Generating Uncertainty Maps:** The required uncertainty maps can get generated by models provided in our supplementary repository (pixel-wise and topology-aware). You must first run the pipelines in the VessQC-Supplementary repository to obtain the final uncertainty map. See: [GitHub.com/SimPutt/VessQC-Supplementary](https://github.com/SimPutt/VessQC-Supplementary)

----------------------------------

### 2. Launching the Application

You can install `VessQC` via [pip]:

    pip install VessQC

To install latest development version :

    pip install git+https://github.com/MMV-Lab/VessQC.git


Once your input data and the uncertainty map are ready, launch napari and the VessQC application.

### 3. Curation Workflow
The typical workflow involves loading the three required files and then iterating through the following steps:

1. **Load Data:** Use the File menu to load the Image, Segmentation, and Uncertainty Map.

2. **Navigate to Uncertainty Peaks:** VessQC provides tools to automatically jump to the highest uncertainty regions. This is the core of the guided curation process.

3. **Review and Edit:** Examine the 3D and 2D views at the high-uncertainty location. If an error is identified, use the provided annotation tools to correct the segmentation mask.

4. **Iterate:** Continue navigating to the next highest uncertain location and repeat the review and edit process.

5. **Save:** When done, save the final, curated segmentation mask.

## Related Repositories
- VessQC-Supplementary: Repository containing the segmentation models and scripts required to generate the pixel-wise and topology-aware uncertainty maps needed as input for VessQC.
